# Agent Instructions

## Porting Skills

When porting a skill from another repository or harness, copy the source files as-is first. Make only the changes required for compatibility with the target harness.

Do not rewrite, polish, normalize, restructure, or invent the skill's wording, style, examples, phase names, formatting, or organization. Preserve the source behavior and authorial style, including capitalization, punctuation, and section order.

Do not remove content unless it is incompatible with the target harness. Do not add content unless it is required for compatibility. If a change is not clearly required, leave it unchanged and discuss it before editing.

Keep the porting diff minimal and compare the result against the original source before considering the port complete.
